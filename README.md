# متابعة التلاميذ — الدروس الخصوصية

تطبيق web لمتابعة تلاميذ برنامج الدروس الخصوصية (من السنة الخامسة إلى التاسعة + السادسة عن بعد).
الهدف: الولي يطّلع على تقدّم ابنه (الغيابات، ملاحظات كل معلم في كل مادة، ملاحظات الإدارة).

## الأدوار

| الدور | ماذا يستطيع |
|---|---|
| **الإدارة** | التلاميذ (صورة، مؤسسة، عنوان، مواد أو Pack، حالة: يدرس / في الانتظار / خرج / متوقف)، المعلمون، الأولياء (ب.ت.و)، المواد، استيراد قائمة، الخلاص الشهري (prorata، مجاني)، ساعات المعلمين وخلاصهم (من جدول الأوقات، غيابات، حصص إضافية، تسبقة)، تأكيد التسجيلات الجديدة، لوحة قيادة |
| **المعلم** | قائمة تلاميذه، جدوله، تسجيل الحضور للقسم، ملاحظات (السلوك / المستوى)، مهام عامة لكل القسم — **في مواده فقط**؛ وساعاته وخلاصه شهرًا بشهر طيلة السنة |
| **الولي** | يسجّل نفسه وأبناءه من الرابط `/#/register`، ويرى أبناءه فقط: الغيابات، الملاحظات، مهام القسم، والوضعية المالية شهرًا بشهر |

المستويات: من الخامسة إلى التاسعة أساسي + السادسة أساسي (عن بعد).
المواد الافتراضية: العربية، الفرنسية، الإنجليزية، الرياضيات (كل المستويات) وعلوم الحياة والأرض (التاسعة فقط).
الإدارة تزيد مواد أخرى من صفحة «المواد» وتحدّد في أي مستوى تُدرّس كل مادة.

## النشر على Netlify

- الواجهة في `public/`، والـ API دالة Netlify في `netlify/functions/api.mjs` (منطقها في `lib/app.js`).
- قاعدة البيانات Netlify Database (Postgres)، تتكوّن تلقائيًا، والجداول في `netlify/database/migrations/`.
- حساب الإدارة `admin` يُنشأ أول مرة بكلمة السر الموجودة في المتغير `ADMIN_PASSWORD` (في إعدادات المشروع على Netlify).
- بيانات تجريبية (اختياري): `node scripts/seed-demo.js https://<الموقع> <كلمة سر الإدارة>`

## التشغيل محليًا

يتطلب Node.js 20.12 أو أحدث. قاعدة Postgres محلية تشتغل وحدها (في `data/`)، أو استعمل `DATABASE_URL`.

```bash
npm install
npm start                       # http://localhost:3000  (admin / admin123)
node scripts/seed-demo.js       # اختياري: بيانات تجريبية، كلمة السر 123456
```

## الهيكلة

- `lib/app.js` — واجهة REST مع التحقق من الصلاحيات
- `netlify/` — دالة Netlify والجداول (migrations)
- `server.js` — تشغيل محلي
- `public/` — الواجهة (HTML/CSS/JS بالعربية، اتجاه RTL)
- `scripts/seed-demo.js` — بيانات تجريبية
