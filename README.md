# متابعة التلاميذ — الدروس الخصوصية

تطبيق web لمتابعة تلاميذ برنامج الدروس الخصوصية (من السنة الخامسة إلى التاسعة + السادسة عن بعد).
الهدف: الولي يطّلع على تقدّم ابنه (الغيابات، ملاحظات كل معلم في كل مادة، ملاحظات الإدارة).

## الأدوار

| الدور | ماذا يستطيع |
|---|---|
| **الإدارة** | إضافة التلاميذ والمعلمين والأولياء والمواد، ربط كل تلميذ بوليّه، إسناد المواد للمعلمين، كتابة ملاحظات الإدارة، تسجيل وتبرير الغيابات، لوحة قيادة |
| **المعلم** | يرى قائمة التلاميذ، يكتب ملاحظات (السلوك / المستوى / عامة + تقييم) ويسجّل الغيابات **في المواد التي يدرّسها فقط** |
| **الولي** | يرى أبناءه فقط: الغيابات، ملاحظات المعلمين مصنّفة حسب المادة، وملاحظات الإدارة (قراءة فقط) |

المستويات: الخامسة، السادسة، السادسة (عن بعد)، السابعة، الثامنة، التاسعة.

## التشغيل

يتطلب Node.js 22.5 أو أحدث (قاعدة البيانات SQLite مدمجة في Node، لا حاجة لتثبيت خادم قاعدة بيانات).

```bash
npm install
npm run seed:demo   # اختياري: بيانات تجريبية
npm start           # http://localhost:3000
```

- حساب الإدارة الأول: `admin` / `admin123` (غيّره من صفحة «حسابي»، أو حدّده مسبقًا بـ `ADMIN_PASSWORD`).
- الحسابات التجريبية (كلمة السر `123456`): `prof.math`، `prof.fr`، `wali.trabelsi`، `wali.gharbi`.
- البيانات تُحفظ في `data/app.db` (يمكن تغييره بـ `DB_FILE`). المنفذ عبر `PORT`.
- في الإنتاج (HTTPS) شغّل مع `NODE_ENV=production` حتى يكون ملف تعريف الارتباط `Secure`.

## الهيكلة

- `server.js` — واجهة REST (Express) مع التحقق من الصلاحيات
- `db.js` — قاعدة البيانات (SQLite) والجداول
- `public/` — الواجهة (HTML/CSS/JS بالعربية، اتجاه RTL)
- `seed-demo.js` — بيانات تجريبية
